# taste-onboarding

The onboarding page of Taste Engine: a designer connects her accounts, tells about projects she loved, reacts to other people's work, and ends with one command for Claude Code.

Open it: https://y66907-collab.github.io/taste-onboarding/

- Everything she types stays in her own browser and in her own taste repo. The page sends nothing to a server.
- Dictation uses the browser's speech service (Google in Chrome, Microsoft in Edge), only after she agrees.
- This repo is a published copy. The source is `onboarding/index.html` in the private taste-engine repo; update it there and copy it here.
